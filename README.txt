NOAGE 公式ホームページ 公開用一式（2026-11-26）

【まず確認する】
ZIPを右クリック→すべて展開。NOAGE_public フォルダの index.html を Chrome で開く。
同じフォルダ内のファイルを分離しないこと。オープニングは毎回再生、右下からスキップ可能。最初から音ありで再生を試みます。ブラウザが禁止した場合のみ「音ありで再生」ボタンが表示されます。
正式ロゴと動画は添付ファイルをそのまま使用しています。

【GitHub Pages公開】
既存の ryunoage-cmd.github.io リポジトリを開き、NOAGE_public 内の次の7ファイルをリポジトリのルートへ一括アップロードする。
index.html / NOAGE_logo_clean.png / NOAGE_opening.mp4 / config.js / app.js / admin.html / admin.js
フォルダごとではなく中身をアップロード。既存ファイルのバックアップを保管し、同名ファイルは更新する。
README.txt と NOAGE_backend は公開側へアップロード不要。
公開先 https://ryunoage-cmd.github.io/ 、管理画面 https://ryunoage-cmd.github.io/admin.html

【外部サービス接続前の状態】
手入力の概算・Googleマップへのリンク・予約希望枠の選択・依頼内容の作成は利用可能。
自動距離取得、実際の依頼送信、管理データ保存、メール・LINE通知は未接続。仮受付送信ボタンは無効。
90分枠は暫定で11:00／12:30／14:00／15:30からの4枠。通常の当日締切は未確定なので設定していない。
1集荷＋最大8納品先を暫定上限とした。追加料金・割引制度の未決定事項は掲載していない。
日曜は受付停止、祝日や臨時休業日は管理画面で登録する方式。未設定時は要相談表示。
車両寸法、開口部、法令上の積載可能重量、積載例写真は未提供のため数値や画像を捏造していない。

【後で必要な設定（外部サービス）】
1. 連絡先：電話、公式LINE URL、メールを config.js に設定。
2. 予約・管理：同梱 NOAGE_backend を Cloudflare Workers + D1 にデプロイし、そのHTTPS URLを config.js の apiBase に設定。管理トークンはサーバーの秘密設定に保管する。
3. Google Routes API：サーバー用の専用キーを発行し、Routes APIだけに制限。既存のWebサイト制限付きキーはサーバー用には流用しない。課金上限・クォータ・不正利用防止を検討してから公開。
4. メール：Resendのアカウント・送信ドメイン認証・サーバー秘密設定が必要。管理者への新規通知と顧客への仮受付・確定等のメール送信処理は用意済み。
5. LINE：管理者への通知処理は用意済み。顧客へのLINE自動通知は公式LINEと予約者のLINEアカウントの安全な紐付け（LINE Login等）を別途実装・設定する必要がある。
6. 実車写真・サイズ、当日締切、祝日、利用規約・プライバシー文面を確定。

HTMLのリンク・ID、JS構文、ChromiumへのHTML/JS直接読み込みでスマホ幅・見積計算・予約内容転記・仮受付未送信表示・管理画面初期表示を確認。実際の動画再生、外部API接続、データベース、メール、LINE、GitHub Pagesへの反映は未確認。
公開前に外部APIのレート制限・ボット対策、データ保持と削除ルール、管理権限、送信テストが必要。
